## Privacy boundary

No raw vehicle, physiology, EEG, eye-tracking, video, checkpoint, or per-event prediction data are published. Claude history is included only as a sanitized public copy: JSONL structure and analysis content are retained, while credentials, contact details, signatures, and machine-local root paths are replaced.
