# 验证协议草案

- 群体外层：subject-disjoint，并按原始/8月数据域和刺激类型分层报告。
- 目标驾驶员内层：完整早期recording校准，完整后期recording测试。
- 基线：零历史群体模型、仅普通驾驶历史、普通历史+少量已完成事件。
- 防泄漏：同一recording不得跨训练/测试；刺激后未来轨迹、未来主动作方向和未来生理不得进入对应预测时刻输入。
- 任务拆分：动作选择、反应时延、强度、条件轨迹、车辆响应分别评价；车辆模块真实操作输入与端到端预测操作输入分开。
- 进入模型阶段条件：刺激语义映射闭合、候选标签人工抽查通过、低频类最小驾驶员覆盖达标、时间顺序无歧义、隐私和一致性检查持续通过。
- 本轮不训练Transformer，也不声称Transformer有效。
