## Claude 最后一段完整分析

跑完了 5 个实验，**我自己提的 5 个假设里被证伪了 4 个**——但证伪的方式给出了这个项目 300+ 版一直缺的那个统一解释。

## 核心结论：驾驶员反应有两层结构，你一直在优化不可预测的那一层

留出的 3 个被试（cwh / lxy / rjy，含历史上最难的两个）：

| 层 | 维度 | 留出 R² |
|---|---|---|
| **可预测层** | 有符号峰值（方向×幅值）@2s | **0.886** |
| | 终点偏移 @1s | 0.824 |
| | 绝对峰值 @2s | 0.519 |
| **不可预测层** | 响应起始 | 0.196 |
| | 峰值时刻 | 0.120 |
| | 反向修正次数 @2s | **−0.073** |

而且这个分离在**整条观测时间轴上都成立**——哪怕已经看了 1 秒真实反应，时刻和反打仍然抬不起来（图 A 里红线始终贴地）。

逐点曲线 RMSE 是这两层的混合，且被不可预测的那层主导。**这就是为什么换更深网络、加候选门控、扩样、修幅值全都无效——可预测的那层其实早就被捕获了。**

## 四个被证伪的假设（都带负对照，这是关键）

**1. 机制条件化无效。** 我上一轮很看好的 `scene_type`，加进去后所有增量都被负对照复现甚至超过：`peak_time` 上表现最好的居然是 N3（**打乱**的被试先验，0.0733）。没有这三个负对照，"机制条件化让峰值时间 +0.010"就会被当成战果报出去。最可能的解释是曲率/mu/横向偏移历史已经把粗粒度机制信息包含了。

**2. 被试因果幅值先验无效**（A2 ≈ A0，打乱版有时更高）。

**3. 幅值-形状解耦被证伪。** 我推断"时刻不可预测→L2 把峰抹平→high-under"，所以解耦应该抬高 peak_ratio。结果 M3 在每个分层都更差（强响应 MAE 0.4095 vs 0.3837，逐被试只 2/12 更优）。**直接逐点回归能按样本自适应形状，已经接近该信息条件下的最优。**

**4. "锚点高 R² 只是动量外推"也不成立** —— 线性外推在锚点处比"保持不动"还差 42.7%（MAE 1.1311 vs 0.7929），模型 0.3837。模型做的是真预测。同时我发现 Phase 1 那个 0.48 的 R² 跳变是**方差分母假象**（MAE 在两处几乎相同），跨 offset 只能看 MAE。

## 唯一被证实且可操作的发现：1 秒时域是错的

| | 1s | 2s |
|---|---|---|
| 峰值落在窗口最后一点 | **68.4%** | 21.9% |
| 峰值幅度中位 | 0.939 | **1.438** |
| signed_peak R²（dev） | 0.640 | **0.754** |
| signed_peak R²（留出） | 0.780 | **0.886** |

**1 秒窗口把 68.4% 的响应截断了**——响应结束时还在增长，峰值幅度中位数被低估 53%。而且主可预测维度在 2 秒下**更好**，dev +0.113、留出 +0.106 两处一致。

关键的是我顺手排除了另一种解释：去掉删失后（68.4%→21.9%，`peak_time` 目标标准差从 0.191 涨到 0.429），时刻/反打的 R² 纹丝不动（+0.004~+0.009）。**所以那两维是真的信息上限，不是窗口太短的假象。**

2026-07-18 转向 1 秒契约的决定值得用这组数据重新审视——它有落进 2026-04 你们自己识别过的"缩短 horizon 换指标"陷阱的风险。

## 我建议的三件事

1. **主任务时域改回 2 秒**（或至少补一次正式 1s/2s 对照）。这是契约级决定，需要你拍板。
2. **论文主张改到幅值域**：报"有符号峰值的跨被试可预测性 0.886"，把时刻/反打作为已量化的 limitation 明写。这比继续报逐点 RMSE 诚实得多，而且是个站得住的贡献——你证明了驾驶员反应哪些维度可预测、哪些不可预测。
3. **和 R380 不确定性门控合流**：这轮给了它一个物理解释——"何时可信"由维度决定，幅值可信、时刻不可信。这正好解释了为什么 R380 的置信带在 high 组条件覆盖只有 0.66。

如果还要攻时刻和反打，得承认那需要新通道（方向盘力矩、手部动作、视线），是采集决策不是算法决策。

一个必须说的口径提醒：留出 R²（0.886）比 dev OOF（0.754）高，因为 test 只有 3 被试且训练用满 15 被试。**方向可信，绝对值不能直接当泛化性能引用。**
