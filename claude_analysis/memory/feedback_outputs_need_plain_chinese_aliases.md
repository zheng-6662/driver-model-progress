默认让输出更易懂：专业术语、指标名、实验判断优先配稳定中文别名或固定解释入口，而不是每次重复写长段术语说明。

**Why:** 用户觉得当前 Claude/Codex 输出里英文和自造术语太多，阅读负担高；但也不希望每次结果都额外附一份长解释，影响紧凑性。

**How to apply:** 在实验汇报、指标比较、结论说明里优先用短中文结论 + 稳定术语映射；复杂术语放到统一词典/对照表/按需解释机制里，而不是每次全文展开。
