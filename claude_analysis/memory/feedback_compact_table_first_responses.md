Prefer concise, scan-friendly responses with short conclusions and tables for metrics/experiment status when possible, while keeping each line reasonably full so the chat does not become overly tall.

**Why:** Long narrow prose is hard for the user to read in their current interface; they want information preserved but presented in a denser, more readable layout.
**How to apply:** For status summaries, experiment comparisons, and next-step recommendations, default to brief bullets plus markdown tables; keep lines a bit longer instead of breaking every clause into separate short lines; avoid long paragraph-heavy answers unless the user asks for depth.
