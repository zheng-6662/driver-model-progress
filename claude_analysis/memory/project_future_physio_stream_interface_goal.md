当前模型主线未来需要支持介入生理信号流接口。

**Why:** 用户希望后续模型不只处理车辆/事件侧输入，而是为未来在线接入生理信号流预留兼容性与扩展空间。

**How to apply:** 设计下一阶段 baseline-conditioned reaction-state-aware 主线时，应优先把输入接口、状态表征和条件化方式做成可扩展结构，便于后续加入生理分支；但当前主线验证仍应先用更稳定的车辆/事件路径完成，不要为了提前接生理信号而让当前任务发散。
