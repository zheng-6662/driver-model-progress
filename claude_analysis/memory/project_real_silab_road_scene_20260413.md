当前真实实验所用的道路场景，应以新的 SILAB 文件计算结果为准；此前拷贝进项目的道路场景版本是旧版本，不代表真实实验使用的场景。

**Why:** 用户澄清当前这版不是额外更换的“新道路轨迹图”，而是对齐真实实验的正确 SILAB 场景来源；之前项目里用到的拷贝版本是老版本，可能导致道路相关列与真实实验不一致。

**How to apply:** 今后凡是检查或重算道路相关特征（如曲率、横向偏移、road type、参考线匹配）时，默认先核对其是否来自新的 SILAB 场景计算结果，而不是沿用旧拷贝版本。
