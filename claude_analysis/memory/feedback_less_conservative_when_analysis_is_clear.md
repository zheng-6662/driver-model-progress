当 Claude/Codex 已经把问题和风险分析清楚后，可以比默认策略更主动，直接推进合理实验，不必每次都收缩到最小执行方案。

**Why:** 用户明确表示当前方法有点过于保守，只要前置分析已经充分，就可以直接放开手去尝试。

**How to apply:** 在本项目里，如果实验变量、对照口径、fairness 风险和执行边界都已经明确，就可以直接启动合适的实验，而不是反复只给最小方案；但仍应避免会破坏 split、公平性或共享状态的高风险动作。
