---
name: 极限工况驾驶员反应建模方向
description: 当前项目核心目标转向极限工况下驾驶员真实反应建模，而非僵化的固定2秒方向盘轨迹预测。
type: project
---
当前项目正在研究极限工况下驾驶员真实反应建模，现阶段发现未来 2 s 方向盘轨迹预测前 1 s 尚可、后 1 s 明显失真，因此研究目标更适合转向“未来一段时间驾驶员反应映射到动作表征”的预测，如方向盘角、方向盘角速度、横纵向速度等；老师建议考虑先做驾驶员操作模式分类/聚类，再进行分模式训练或条件预测。

**Why:** 固定 2 s 长时域轨迹在极限工况下不一定是最合理目标，用户更关心真实反应及其对后续辅助驾驶协同介入的参考价值，也希望形成“什么样的驾驶员会有什么样的行为”这一类可解释结论。

**How to apply:** 之后在该项目中讨论建模、实验设计、文献检索和汇报思路时，应优先围绕短时反应、动作表征、多目标建模、操作模式划分与共享控制价值来组织建议，而不是默认继续优化固定 2 s 单一轨迹回归。
